<strong>84297 FMD verification window to add serial number manually is not triggered</strong>
<ul><li>On the pharmacy POS, the FMD manual serial number entry panel (prescription picking and over-the-counter sales) no longer skips waiting for the user to press OK or Cancel.</li><li>Previously the panel showed but the sale/pick continued immediately without the entered serial number actually being captured or verified.</li></ul>
<strong>87216 Caption missing from LSC PH Dispense Order Detail</strong>
<ul><li>9th column's caption was missing from the Dispense Order Detail report. This was fixed.</li></ul>
<strong>89796 Pharmacy customer order panel defaults</strong>
<ul><li>The Pharmacy Administration Task that handles the creation of the UI POS elements for the Customer Orders functionality now correctly updates the panels.</li></ul>
